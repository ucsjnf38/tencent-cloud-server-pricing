## 腾讯云服务器收费由哪几部分构成？

主要就是三部分：实例规格（CPU+内存）、存储（系统盘、数据盘）、网络（公网带宽），GPU实例还包括GPU卡。腾讯云在产品推荐区写得很直白：费用会因镜像、系统盘、带宽等配置不同而有差异，实际消费以使用情况为准。

拆开来看：

- **实例**：CPU和内存的组合。腾讯云把实例分成不同实例族，标准型 S5 用 Intel 处理器，标准型 SA2 用 AMD EPYC ROME 处理器，蜂驰型定位经济型、使用体验和标准型一致但价格更低。
- **存储**：系统盘通常打包在报价里（产品页常见 50G 系统盘），数据盘要另算。
- **网络**：产品页推荐的配置一般按 1Mbps 带宽计价，带宽往上加，价格也跟着变。
- **镜像**：官方明确说明镜像不同也会影响费用，购买时别忽略这一项。

这也是为什么两台参数看起来一样的机器，账单可能差几百块——带宽、系统盘、实例族，任何一项不同，价格都会变。

## 包年包月、按量计费、竞价实例、包销，四种模式怎么选？

长期稳定业务选包年包月，短期或不确定的选按量计费，可中断的任务看竞价实例，GPU 批量采购才涉及包销计费。腾讯云 GPU 云服务器文档列出的购买方式就是这四种。

**包年包月**是先付费后用，买一年、三年或五年，单价通常比按量计费低，适合网站、企业系统这类会长期跑的业务。

**按量计费**按小时结算，适合临时测试、短期扩容。官方计费文档里有个示例：S2.MEDIUM4 的按量单价是 0.32元/小时，包年包月单价 102元/月——注意，这是文档用来演示计算规则的示例数字，不是当前报价，实际价格以购买页为准。

**竞价实例和包销计费**出现在 GPU 云服务器的购买方式里，面向特定场景，普通建站用户基本用不到，这里不展开。

## 升配要补多少钱？

按天补差价。腾讯云官方文档给出的公式是：

**升配费用 = 按月升配差价 × 升配月数 × 适用折扣**

其中按月升配差价是新老配置按月单价的差额；升配月数 = 升配天数 ÷ (365/12)；升配天数 = 资源到期时间 − 当前时间。折扣按升配月数匹配官网适用折扣。

几个容易忽略的细节：

- 升配不影响到期时间，该哪天到期还是哪天。
- 升配可以用代金券和平台赠送金抵扣。
- 运营活动的升配策略与包月实例规则一致。

文档里有个完整示例：1核1GiB（65元/月）升到 2核4GiB（218元/月），按月差价 153元，剩余 244天，适用 88折，最终补 1080.07元。文档特别注明这是示例价，不是现价。

## 降配能退多少钱？

降配退款 = 实例退费费用 − 新规格新购费用。算下来大于 0 才退钱，小于等于 0 照样给你降配，但不退费。

购买时用的折扣和代金券不予退还，这一点在降配前要算进去。

官方文档里的两个例子很能说明问题。一个买了 1年 S2.MEDIUM4 的用户，用了 8个月后降配到 S2.SMALL2：原实例退货费用 197.84元，新购 240元，退款 −42.16元，不退费。另一个人用了 3个月零 3天降配，同样的操作，退款 111.68元。

## 买之前值得确认的几件事

**结算价才是最终价。** 产品页标价通常按 1Mbps 带宽、50G 系统盘计算，带宽加到 5M、系统盘加到 200G，总价就变了。对比价格时，先把带宽和磁盘拉到同一个水平。

**轻量套餐有月流量包。** 从 200GB 到 8000GB 不等，用超之后怎么处理，购买页有说明，别等账单出来才看。

**实例族决定价格下限。** 蜂驰型定位经济型、使用体验和标准型一致，官网标价 531元/年的 2核2G 比很多活动机型还便宜，预算有限的中小业务可以优先看它。

**降配不一定退费。** 上面算过了，用掉大半时长再降配，退款金额很可能是负数。

**到期前记得处理数据。** 回收站只保留 15天，重要数据提前备份或续费。
